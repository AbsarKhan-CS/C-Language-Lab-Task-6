# C-Language-Lab-Task-6
PF Lab Task 6
Task 1: Cinema Seat Booking
A cinema hall has 5 rows and 8 seats per row. Seats are stored in seats[5][8] (0 = empty, 1 =
booked). Read the booking status of every seat, then print the seating map using . for empty and
X for booked. Also report how many seats are free in each row and in total.

Task 2: Student Marks Sheet
A teacher has 6 students and 4 subjects. Read the marks into marks[6][4]. Print each student’s
total and average, each subject’s class average, and the name of the subject (by number) where
the class performed best.


Task 3: Weekly Temperature Report
A weather station records the temperature at 4 times of day (morning, noon, evening, night) for 7
days in temp[7][4]. Find the hottest and coldest readings with their day and time slot, and list
the days where the noon temperature was above the weekly noon average.


Task 4: Shop Sales Comparison
A shop sells 5 products across 3 branches. Read monthly sales into sales[3][5]. Print the total
sales per branch, total sales per product, the best-selling branch, and the product with the lowest
sales overall.


Task 5: Hotel Room Occupancy Grid
A hotel has 4 floors with 6 rooms each, stored in rooms[4][6]. Read 1 for occupied and 0 for
vacant. Find the floor with the most vacancies. Then check whether any floor has 3 or more
consecutive vacant rooms, and print the floor and the starting room number.


Task 6: Tic-Tac-Toe Winner Checker
Read a finished 3×3 board using scanf(" %c", &board[i][j]) (characters X, O, or -). Check
all rows, columns, and both diagonals, then print the winner or declare a draw.


Task 7: University Result System
A university has 3 departments, 4 students per department, and 5 subjects each, stored in
marks[3][4][5]. Print every student’s average, the topper of each department, and the
department with the highest overall average. Mark any student with a subject below 40 as
“FAIL”.


Task 8: Warehouse Inventory
A warehouse has 3 buildings, 4 shelves per building, and 5 slots per shelf, stored in
stock[3][4][5]. Each element is the number of items in that slot. Print the total stock per
building, find the single fullest shelf and report its building and shelf number, and list every slot
with fewer than 5 items as “needs restock” along with its [building][shelf][slot] position.


Task 09: Library Book Catalog
A library shelf holds 5 books. Read each title (with spaces) using the scanset scanf(" %[^\n]",
titles[i]) into char titles[5][50], and read its number of copies into an int. Then:
1. Print the catalog as a neat table.
2. Count the vowels in each title using nested loops.
3. Let the user enter a single letter, then show which titles start with that letter.
4. Print the title with the most copies.
